Hypersomnia — «Лес отвечает»: звук рубки в выживании

ОСНОВА
Исходники из src.zip, присланного пользователем вместе с отзывом о тесте. Изменён client/ForestReplyClient.java; добавлены forest/ForestReplyRhythm.java и devtest/java/com/hypersomnia/forest/ForestReplyRhythmSelfTest.java. Другие файлы проекта не заменяются.

ЧТО ИЗМЕНИЛОСЬ
- Вместо двух одиночных звуков разрушения для каждого из двух брёвен воспроизводятся три знакомых WOOD_HIT с интервалом 4 тика, затем WOOD_BREAK. Получается две короткие серии из одной неподвижной скрытой точки. Это имитация звуком: дерево, блоки и предметы не меняются.
- Интервал между разрушениями основывается на недавнем темпе игрока (6–60 тиков), но для различимых серий ограничен снизу 16 тиками; для диагностического режима с исходным интервалом 12 используются 16. Первая серия длится 12 тиков, финальный звук второй в диапазоне 28–72 тиков после первого удара. Оценить ритм и баланс на слух.
- Удары используют ту же громкость и высоту, что прежний ответ, чтобы их можно было услышать на расстоянии 8–12 блоков; это не точное воспроизведение затухания и громкости собственного удара игрока.
- Подтверждение серверу и обычный индивидуальный кулдаун теперь приходятся на первый фактически активный звук удара, а не разрушения. Если событие прервано после подтверждения, полный кулдаун уже сохраняется. Команда test по-прежнему не расходует реальные ограничения.
- До каждого последующего звука повторно проверяется скрытость источника; отключённый звук, недоступный чанк, удаление, экран или приоритетное событие прерывают серию. Активные звуки останавливаются. Шанс, отсчёт суток, таймеры других событий, выбор источника и сеть не менялись.

ПРИМЕНЕНИЕ
Скопировать содержимое src/ в проект с сохранением структуры. Если после присланного src.zip клиентский ForestReplyClient.java менялся, объединить правки вручную, а не перезаписывать их. Альтернатива — сначала проверить CHANGES/forest_reply_survival.patch через git apply --check, затем применить его из корня проекта. Не применять патч и копирование одновременно. Патч рассчитан на точную версию из присланного src.zip.

ПРОВЕРКИ
90 автоматических проверок фактического класса ритма с Java 21 API; 42 проверки фактического клиентского обработчика с заглушками Minecraft (серия, подтверждение первого удара, пауза, конфликт, скрытость, отключение звука). Синтаксис Java проверен. Эти проверки не заменяют компиляцию против реальных зависимостей и запуск Minecraft: архив содержит только src/, а не полный Gradle-проект.

В игре: повторить /hypersomnia forest test в лесу, прослушать оба цикла и их громкость на разных расстояниях, проверить обрыв при повороте/приоритетном событии и отсутствие изменений дерева. Отдельно проверить естественный запуск, сохранение кулдауна, настройки громкости, паузу, клиент/сервер и другие сценарии из карточки. Новый звук ещё не проверен пользователем в игре.
