Hypersomnia — обновлённый коридор палат

Изменён только src/main/java/com/hypersomnia/nightmare/NightmareBuilder.java,
на основе предыдущего пакета коридора. Порталы и их настройка скрытия игроков,
очередь входа и прочие системы не изменяются.

Планировка: коридор в три блока с контрастными краями пола, светлыми стенами,
холодной полосой, рамами широких входов и смотровыми окнами. По обе стороны —
палаты с входом шириной два блока и свободным центральным проходом до дальней
стены. Три варианта: две койки с тумбами; одна койка с тумбой и шкафом; одна
койка с тумбой и рабочей поверхностью. У коек изголовья. Мебель декоративная,
без контейнеров и реальных кроватей, чтобы не давать лут и не запускать сон.
В палатах приглушённый свет; источник скрыт, потолочная панель обозначает лампу.
Варианты повторяются через 24 блока — на величину переноса портала.

Установка: скопировать src/ поверх предыдущих пакетов. Если вы меняли этот файл,
объедините изменения вручную. Альтернатива копированию — проверить
 git apply --check CHANGES/ward-redesign.patch
затем выполнить git apply CHANGES/ward-redesign.patch. Не делать оба варианта.
Затем выполнить gradlew.bat build. Новая версия требует прежнюю систему порталов.

ВАЖНО: существующая палата не перестраивается автоматически. Для просмотра в
существующем мире сначала сделайте резервную копию: старая команда
/hypersomnia_nightmare build ward перезаписывает все блоки в области коридора,
включая установленные игроками блоки и содержимое контейнеров. Выведите всех
игроков из коридора, выполните команду в тестовом/резервном мире, затем входите
/hypersomnia_nightmare enter ward. Не используйте команду в ценном мире без копии.
В ещё не построенном мире новый вариант создаётся при первой постройке, которая
также перезаписывает блоки в выделенной области. Команда build может сообщить,
что порталы ещё загружаются: это не означает, что нужно перестраивать повторно;
для входа используйте enter ward и дождитесь результата.

Проверки: Java 21 и 3194 проверки работающего генератора на упрощённых заглушках:
размер области, проход, размещение коек, точка появления и повтор всех блоков
через 24 позиции. Патч применён к предыдущей версии файла. Это не полная сборка
с NeoForge и не игра: рендер, освещение, реальная коллизия, стык порталов,
прохождение, обновление на сервере и внешний вид должны быть проверены в игре.
