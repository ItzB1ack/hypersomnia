HYPERSOMNIA — пакет «шифр на каждый этаж + интерьер»
База: src.zip из этого чата. В changed.zip — все отличия от него (включая пакеты lift-safety и «этажи»).
Сборка НЕ проверялась (в среде нет Gradle/JDK): нужен runClient, см. [ПРОВЕРИТЬ].

ЦЕПОЧКА ЛИФТА
G (люк, шифр 1) -> B1 (MAIN FEED) -> B2 -[шифр 7]-> B3 -[шифр 8]-> B4 -[шифр 9]-> B5.
MAIN FEED теперь открывает только B2 (LabTuning.FEED_REACHED = 2). Каждый следующий этаж открывает кодовая панель
LIFT ACCESS у двери лифта (справа от двери, слева табличка). Коды зависят от зерна мира (одно на оба мира).
- Шифр 7, B2 -> B3 (замок 6, LOCK_STACKS). Объявление в копировальной: перед копией из каждого ряда хранилища (1-4)
  взяли по коробке; код = цифра листа B2-CHK для места каждой взятой коробки, ряд 1 первым. В хранилище в каждом ряду одно
  место пустое (резная полка без книг). ПКМ по полке: «РЯД r · МЕСТО p». Станция отдела учёта WS-B2-01: письмо М. Эшби,
  письмо охраны о кодах лифта, COPY.LOG.
- Шифр 8, B3 -> B4 (замок 7, LOCK_BUFFER). Пульт серверной WS-B3-01: BUFFER.LOG (какие стойки держат буфер и в каком порядке,
  номера по зерну) и письмо Т. Брандта. У стоек 1-12 лампа состояния (светлая — ожидание, красная — буфер удержан) и
  4 лампы адреса 8-4-2-1 сверху вниз. Код = адреса четырёх буферов SOURCE 47 по порядку журнала; буфер копии B2 не вводится.
  Памятка — шкаф на пульте.
- Шифр 9, B4 -> B5 (замок 8, LOCK_WARD, «код директора»). В мире снов дверь палаты 2D заложена; когда рядом игрок, за ней
  стучат: на каждую цифру — удары по номеру ряда кнопки, пауза, удары по номеру столбца (панель 1-2-3 / 4-5-6 / 7-8-9 / C-0-<,
  0 = ряд 4, столбец 2), 4 цифры, тишина, повтор. Правило — записка в палате 2D реального мира; станция поста WS-B4-01:
  письмо охраны (панель видна из окна 2D) и письмо ночной медсестры. Окно 2D действительно смотрит на панель.
Подсказки для отладки: /hypersomnia_lab index печатает все три кода; index reroll перекрашивает стойки и пустые места.

ИНТЕРЬЕР (чертежи B2-B5 обоих миров переписаны, у всех этажей одна схема: лобби у лифта, комнаты по бокам, низ за стеной)
- B2 ARCHIVE: копировальная (терминалы, объявление, лист B2-CHK, тележка), читальный зал со стойкой выдачи у входа в
  хранилище, отдел учёта (станция, картотека), хранилище: 4 ряда по 8 мест с табличками на торцах, сортировка, картотека.
- B3 SERVERS: хранилище лент, операторская (раковина, столик, рабочее место), лобби со статус-экранами; внизу зал стоек
  (холодный коридор между рядами 1-6 и 7-12, кондиционеры), SERVER CONTROL с окнами в зал, помещение ИБП (щиты, батареи).
- B4 MEDICAL WING: аптека (стойка выдачи лицом к двери), пост медсестры лицом к палатам, палата 2A (кровати, ширма),
  внизу 2B (на уборке), 2D (Nora: кровать у окна, выписка, рисунок, записка, детский столик), 2C (свободна).
- B5: кабинет директора (стол лицом к двери, стул посетителя, контракт), секретарь у двери директора, SESSION CONTROL
  (пульт у окон в зал), тёмный зал капсул.
- Сон B2-B5: те же планы без документов и панелей; мониторы со «снегом», стулья развёрнуты, ряды B2 все подписаны «РЯД 1»,
  стойки B3 тёмные, кроме одной, дверь 2D заложена (стук).
- real_b1: табличка у лифта «ЛИФТ | B2 И НИЖЕ | ОТ MAIN FEED».
- Русский перевод всех табличек B2-B5 (раньше его не было).

ДОЛГОСРОЧНЫЕ РЕШЕНИЯ (приняты без вопросов)
1. LabProtection: в выживании блоки этажей нельзя сломать или взорвать (иначе любой шифр обходится киркой).
   Творческий режим не ограничен. Выключатель и границы: LabTuning.PROTECT*.
2. LabSavedData.DATA_VERSION = 2: в старом мире при загрузке доступ ниже B2 срезается до открытых замков LIFT ACCESS.
3. WorldVariant.random(seed, key) — единый источник случайности шифров; LabFixtures перекрашивает мир без пересборки.
4. tools/lab_check.py — проверка всех чертежей: проёмы, крепление табличек и панелей, кровати, ряды и стойки,
   досягаемость от лифта, документы и станции, русские переводы табличек; --png DIR рисует превью.
   Запуск: python3 tools/lab_check.py (сейчас: OK, 12 чертежей, без предупреждений).
5. Server Rack ставится рукой как дверь (верх ставится сам, ломается целиком).
