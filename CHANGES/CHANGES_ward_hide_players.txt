Hypersomnia — игроки не видны через порталы коридора

Изменён только src/main/java/com/hypersomnia/nightmare/WardLoopPortals.java.
В обоих порталах петли включено штатное скрытие игроков Immersive Portals.
Эффект ограничен этими порталами: в их изображении не виден собственный персонаж
и другие игроки; вне картинки портала другие игроки должны оставаться видимыми.
Предметы, мобы, блоки, прохождение и другие порталы не меняются. Шейдеры и
модификации рендера в игре не проверены.

Установка: поверх предыдущих пакетов коридора скопировать src/ в корень проекта.
Если файл менялся у вас после прошлой передачи, объединить изменения вручную.
Альтернатива копированию: git apply --check CHANGES/ward-hide-players.patch,
затем git apply CHANGES/ward-hide-players.patch. Не делать оба варианта.
Собрать gradlew.bat build. В сетевой игре обновить сервер; клиентам нужен мод и
Immersive Portals соответствующей версии.

Уже сохранённая пара обновляется и синхронизируется при следующей проверке
готовности перед входом в коридор. Если после обновления вы оказались уже внутри,
выйдите /hypersomnia_nightmare exit и снова войдите /hypersomnia_nightmare enter ward.
Выход может перемотать ночь. Не использовать build ward для обновления: он может
перезаписать блоки. При повреждённой паре код возвращает ошибку и не меняет её.

Проверка: в резервном мире посмотреть вперёд/назад через оба портала, пройти
через каждый, проверить, что своего персонажа не видно, коридор отображается и
проход работает. В multiplayer проверить видимость других игроков через портал
и вне него, а также с перезапуском мира. compileJava с Java 21 / NeoForge
21.1.235 / Immersive Portals 6.0.7 прошла, 33 проверки менеджера на заглушках;
фактическая картинка в игре, шейдеры и multiplayer ещё не проверялись.
