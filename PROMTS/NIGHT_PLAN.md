### 0.1. Объём и честная оценка

План намеренно больше одной ночи: **28 задач, ~30–45 часов** аккуратной работы.
За 9 часов реально закрыть 5–7 задач. Поэтому порядок — по важности, а не по разделам:
остановиться можно на любом коммите, состояние всегда консистентно.

Если дедлайн близко — не начинать новую задачу, закрыть текущую, обновить журнал и отчёт.

## 1. Стартовый ритуал (один раз, ~15 минут)

1. `git fetch origin main`, `git status`, `git log --oneline -5`. Записать HEAD в шапку.
   Чужие незакоммиченные правки не выбрасывать: если они не мои — один вопрос;
   иначе `git stash` с записью в журнал.
2. Прочитать в ULTRAPROMT: §0 (формат), §1 (гит/сборка), §2 (границы), §3 (канон),
   §4 (конвенции), §5 (карта кода), §7 (что осталось), §8 (ловушки). Не целиком — по разделам.
3. Прочитать `PROMTS/PROMT_NEXT_CHAT.txt`: шапку, последнюю сессию, «ЧТО ОСТАЁТСЯ».
4. Прогнать baseline (раздел 3). Красный baseline — это N0: чинить до всех задач.
5. Начать N1.

## 2. Контракт автономной работы

- Работать непрерывно до конца списка или до реального блокера. Вопрос пользователю —
  только если без него нельзя двинуться. Один вопрос за раз, коротко, по-русски.
- Одна задача = один связный набор правок = **один коммит = один push**.
  Следующая не начинается, пока предыдущая не закоммичена.
- `main` всегда собирается. Красное дерево запрещено.
- Минимальные точечные правки по якорям. Не переформатировать чужие файлы, не удалять
  незнакомый код — сначала разобраться.
- Комментарии и тексты в коде — по-русски, в стиле окружающего кода.
- Субагенты разрешены: `explore` — поиск по коду, `general` — параллельные аудиты.
  Коммитит и пушит только основной агент; результат субагента проверяется компиляцией.
- Часы: в начале задачи `Get-Date`. Меньше ~30 минут до дедлайна — не начинать новую.
- Когда задача упирается в игру: не эмулировать, пометить «нужна проверка в игре»,
  записать в `PROMTS/INGAME_CHECKLIST.md` (N10) и идти дальше.
- Задача распухла — сузить до проверяемого куска, остаток записать как `Nx.1`.

Из корня проекта, всё офлайн:

```powershell
python src/devtest/check_network_sides.py
python src/tools/lab_check.py
```

Baseline 2026-11-10 (проверено, HEAD `886dd91`): всё зелёное —
`compileJava` (только старые deprecation-warnings), `observerSelfTests` (100),
`labSelfTests` (286 + 3 + 8 + 2839), `wardSelfTests` (110), `finaleSelfTests` (513),
`forestReplySelfTests` (15 + 90 + 36), `check_resources.py`, `check_network_sides.py`,

- «Проверено» = компиляция + тесты + чекеры. **«В игре не проверено»** пишется всегда,
  пока пользователь явно не подтвердил обратное.
- Новые self-tests — в `src/devtest/java/...`, подключение через `src/devtest/*.init.gradle`
  по образцу существующих.

## 4. Коммиты, пуш, промты

- Сообщение коммита — по-английски, первая строка ≤ 72 символов, тело: что и почему.
  Если в игре не проверено — так и написать в теле.
- В тот же коммит:
  - `PROMTS/PROMT_NEXT_CHAT.txt` — пункт текущей сессии;
  - `PROMTS/ULTRAPROMT.txt` — затронутый раздел + строка «Обновлено»;
  - `CHANGES/*.txt` — крупный блок (механика, сеть, NBT, ассеты);
  - шапка и журнал этого файла.
- `git push origin main` после каждого коммита. При отказе — `fetch` + `rebase`,
  без `--force` и переписывания истории.
- Косметику и переименования без смысла в промтах не упоминать.

## 5. Решения по умолчанию (не спрашивать)

| Ситуация | Решение |
|---|---|
| Геймплейное число без проверки в игре | оставить текущее, записать «кандидат на тюнинг» |
| Новый текст | сразу EN + RU; EN — авторский стиль, не машинный перевод |
| Новый wire-формат | не менять; если нельзя — новый канал с версией, старый читается |
| Новая механика/класс/команда | `[новое]`, оба промта + `CHANGES/` |
| Неоднозначный баг | сначала воспроизводимый тест, потом фикс |
| Задача распухла | сузить до проверяемого куска, остаток — `Nx.1` |
| Нужна игра | пометить и идти дальше |

## 6. Стоп-лист (ночью нельзя)

- `/hypersomnia_lab rebuild`, `resite` и любые команды, меняющие мир; правка `run/saves`.
- Визуальный и звуковой тюнинг «на вкус», баланс, проверяемый только игрой.
- Удаление ассетов, архивов, истории git; `push --force`, `rebase` чужих коммитов.
- Смена канона: лицо Норы, голос, авторские кадры концовок, природа осколка.
- Отключение проверок и `@SuppressWarnings` пачкой «чтобы собралось».
- Client-only импорты в common; регистрация клиентских payload-хендлеров в common
  (`RegisterClientPayloadHandlersEvent` не использовать).
- Массовые рефакторинги «заодно».

### 6.1. Технические ловушки (из ULTRAPROMT §8, читать перед ассетами)

- `tools/make_documents.py` пишет LF и пережимает старые PNG: после запуска вернуть старые
  файлы байт в байт, оставить только новые.
- `tools/make_furniture.py`: новые текстуры дописывать в конец, иначе изменится
  последовательность ГСЧ и старые текстуры поменяются.
- Lang-файлы: `json.dumps(indent=2, ensure_ascii=False)` + перевод строки; порядок ключей
  не менять; окончания строк сохранять (часть файлов CRLF).
- Чертежи: проём `=` шириной 3, таблички не ближе ±1 от него; карты (station, finale, bed,
  capsule, panel, cabinet) важнее мебели; замки ставятся после мебели.
- После `lab_check.py` удалить `tools/__pycache__`.
- Не читать `.gradle`, `build`, `run`, `.idea`, jar.

### Блок A. Фундамент (≈4–6 ч)

#### N1. Baseline и расхождения промтов (30–60 мин)

`check_network_sides.py` уже сверяет bridge/setup. Дополнить: каждый payload зарегистрирован
на нужной стороне, у каждого есть хендлер, нет client-импортов и method reference в
common/network, канал с версией при изменении формата (ULTRAPROMT §4).
**Сделать:** расширить чекер; сломать файл временно → убедиться, что чекер краснеет → откатить.
**Готово, когда:** чекер ловит искусственную поломку и зелёный на `main`.

пустые значения, запрещённые `§k`/`§m`, ключи без использования (предупреждением).
**Сделать:** расширить чекер, исправить расхождения.
**Готово, когда:** чекер зелёный, правила описаны в промтах.

#### N25. Ресурсы: ссылки и .mcmeta (1.5–2 ч)
Расширить `check_resources.py`: все текстуры/модели/blockstates/звуки из JSON существуют;

**Сделать:** чекер + фиксы битых ссылок.
**Готово, когда:** чекер находит подложенную битую ссылку и зелёный на репозитории.

**Готово, когда:** файл покрывает все открытые пункты; утренний отчёт ссылается на него.
