Продолжаем разработку мода Minecraft «Hypersomnia». Это перенос из прошлого чата, ниже текущее состояние.

## Проект
- MC 1.21.1, NeoForge 21.1.235, Java 21, пакет com.hypersomnia. Жанр: медленный analog horror.
- Приложены: hypersomnia_src_full.zip (полный src: director + tape, 384 записи, без devtest), PROMT, COMMONPROMT, ARCHIVEPROMT, CHANGES_director.txt, CHANGES_tape.txt.
- Если в песочнице есть /data/hs (см. «Окружение»), работай там. Иначе распакуй архив и подними сборку заново.

## Жёсткие ограничения
1. Архитектуру не менять: числа в *Tuning, проверка на сервере, сеть в *Network, клиентское состояние в *State без client-импортов.
2. Не делать параллельных версий существующих систем, только расширять их.
3. Медленный analog horror. Глаза только на лице Фрагмента, в небе сна и в сцене у кровати. В интерфейсах и шифрах глаз нет.
4. Не имитировать движения и позы игрока. Сцена у кровати без звука.
5. До финала не раскрывать, что Фрагмент — часть игрока. Слово «insomnia» не использовать.
6. Игровые тексты на EN в коде и данных, русский через ru_ru.json. Тон холодный, служебный.
7. Не выдумывать API, сомнительное помечать [проверить]. Не писать, что компилируется или запускается, без проверки.
8. Палитра #03050A, #1E2A34, #4A5E70, #DDE6EC. Красный #8A2030 только для ограничений и штампов на документах. CRT и шум вторичны, текст должен читаться.

## Правила ответов
- По-русски, коротко, без похвалы.
- Не больше ОДНОГО вопроса за ответ, с вариантом по умолчанию («по умолчанию делаю X»).
- Новые дизайн-решения помечать [новое].
- Честно разделять «проверено» и «не проверено».
- Результат сразу архивами: zip только с изменёнными и новыми файлами (с путями), CHANGES_<пакет>.txt (что, зачем, что проверено, что нет), png-превью при визуальных изменениях, полный src zip.

## Окружение (если песочница та же)
- Рабочая копия /data/hs/work/src, проект сборки /data/hsbuild. Синхронизация: python3 /data/hs/sync.py (devtest не трогает).

  - ClientShot (режимы dump/panel/interior/docs/hover/plan/director/tape, флаги в run/*.flag);

- Переменные: export JAVA_HOME=/data/tools/jdk-21.0.13+9; export PATH=$JAVA_HOME/bin:/data/tools/gradle-8.14.3/bin:$PATH

- Клиент: setsid nohup gradle runClient при DISPLAY=:99 (Xvfb). client.log читать только через cut -c1-200: там огромные строки classpath.
- Перед новым пакетом скопировать текущий src в /tmp/prev8/src как базу для diff. Шаблон упаковки: /tmp/pkg_tape/pack.py (поменять BASE, TAG, пути). Классы MC для javap: /tmp/mcjar. /tmp может быть очищен, тогда собрать заново.
