# 15. ЗАДАЧА: КОШМАРЫ (добавить к основному промту; правила пунктов 0-4 действуют)

## 15.1 Состояние из прошлого чата (отправлено, применение не подтверждено, запуск не проверен)
- Погоня, лазание: ChaseTuning.PATH_SCRAMBLE_MAX=3, PATH_SCRAMBLE_COST, PATH_UNDER_DIST; ChasePath.find(from,to,max,partial), Route.partial, Node.scramble, scrambleHeight(); ChaseHandler.repath и under(). Игрок на столбе 2-3 блока: осколок лезет по стене; выше: стоит под ним без стука до конца бега (ESCAPED). Причина прежней ошибки: путь по следу упирался в блок, срабатывал BLOCKED (фаза для дверей) и через 70 тиков осколок исчезал.
- Поимка = сон: в ChaseHandler.step (фаза CAUGHT) после end(O_CAUGHT) вызывается DreamTransition.enter(player); import com.hypersomnia.dream.DreamTransition.
- Не проверено: реакция на спуск игрока до REPATH_FAIL_TICKS (1 с); вертикальный подъём вдоль стены; чёрный кадр поимки не обрывается на телепорте.

## 15.2 Что делаем
Кошмар = отдельный режим сна: игрок попадает в заранее построенное место мира снов и действуют особые правила. Обычный сон (кровать) остаётся как есть. Сценарий выбирается по причине входа. Цель этого чата: инфраструктура + пилот №1.

## 15.3 Решения (канон кошмаров)
- Место: заранее построено в измерении снов, в фиксированной зоне, по образцу LabBuilder/LabFloors; состояние в SavedData. Тот же слой мира снов, не новые измерения.
- Осколки в кошмарах только клиентские «призраки» (как ObserverGhost), в мир не добавляются; урона нет (до стадии 5 нигде); лицо Nora не показывать; глаза только на лице осколка (новых глаз в интерфейсе нет).
- Числа только в NightmareTuning (общий код, без клиентских импортов); клиентское состояние NightmareState без клиентских импортов Minecraft; пакеты в NightmareNetwork; сервер в NightmareHandler (@EventBusSubscriber); отладка /hypersomnia_nightmare enter <id>|exit|status; данные: DreamData.kind (или отдельный Data Attachment, copyOnDeath).
- Выход из кошмара: по таймеру или по действию, на выходе усталость, безумие и последствия задаются сценарием.
- Тексты: внутриигровые по-английски, холодный служебный тон, RU в ru_ru.json; ключи hypersomnia.nightmare.<id>.<индекс>.

## 15.4 Кошмары (триггер -> место -> правило -> выход)
1. «Коридор палат» (ПИЛОТ). Триггер: поимка осколком. Бесконечный коридор медкрыла (палаты Nora): игрок доходит до конца и незаметно возвращается на начало (телепорт назад на длину сегмента с сохранением смещения [проверить] на стыке). В каждой палате стоит клиентский осколок и «спрашивает»; эскалация по номеру круга: «Where am I?» -> «Why didn't you save her?» -> «How can you sleep?». Выход: палата, где осколка нет и на кровати пустой лист (связка с drawing_blank).
2. «Шахта». Триггер: принудительный сон на 100% усталости (FatigueHandler.finishForcedSleep). Лифт 3x3 (LabLift) едет по этажам, которых нет (B6, B7, ...); двери открываются в пустые коридоры; сон не даёт отдохнуть. Выход: этаж «0».
3. «Обход». Триггер: откат после шприца (найти в SyringeHandler, файл запросить). Ряд капсул 1-46 с пометками канона («Cognitive collapse», «Sleep did not resume», «Subject unresponsive», «Terminated during session», «Dissociation, discharged»); осколков нет ни в одной (осколок только у 47). Бежать нельзя, шприцы на полу не трогать. Выход: дойти до капсулы 47 и лечь.
4. «Сеанс 47». Триггер: сон после находки воспоминания 6 (Incident Protocol). Зал сеансов, часы 02:41 -> 03:07 -> 03:12 -> 03:13; игрок пытается «успеть», не успеть нельзя (столп 2). Выход: часы доходят до 03:13, обрыв.
Новые кошмары придумываются позже; не плодить без сюжетной причины (столп 5).

## 15.5 Точки входа в код (из присланного zip, строки могут съехать)
- dream/DreamTransition.enter(player): сохраняет возврат, ставит DreamData.inDream, ticksLeft=DreamTuning.DURATION_TICKS, телепортирует в измерение по тем же координатам (findSafe). Для кошмара нужна версия с целевым местом и kind.
- dream/DreamTransition.exit(player): возврат, пропуск ночи, SleepPenalty.restFatigue, ChaseHandler.onWake, следы/записки.
- dream/DreamHandler: тик сна (кровать -> enter, таймер -> exit, adoptUnexpectedArrival).
- chase/ChaseHandler: фаза CAUGHT (CAUGHT_TICKS=34) -> end(O_CAUGHT) -> DreamTransition.enter. caught() добавляет усталость +25% и безумие +1.
- server/FatigueHandler.finishForcedSleep -> DreamTransition.enter.
Нужно запросить, когда понадобятся: DreamData, DreamTuning, DreamDimension, LabLift, LabFloors (фрагмент медкрыла), SyringeHandler (откат), ObserverGhost.

## 15.6 План (5-8 шагов)
1. NightmareTuning, NightmareDefs (id, триггер, место, длительность, выход, последствия), kind в DreamData.
2. Вход: DreamTransition.enterNightmare(player, id); перевод поимки и принудительного сна на него; обычный сон не трогать.
3. Построитель «Коридора палат» (NightmareBuilder) в фиксированной зоне, SavedData.
4. Цикл коридора (телепорт назад), счётчик кругов, пакеты NightmareNetwork.
5. Клиент: осколки в палатах (призраки), тексты по кругу, пустая палата, выход.
6. Отладка: /hypersomnia_nightmare; проверка стыка и выхода.
7. Затем №2-4 по одному.

## 15.7 Не проверено / риск
Телепорт-цикл без видимого стыка; поведение клиентских призраков в закрытых комнатах; сохранение места в SavedData между перезапусками; всё остальное по списку риска пункта 3.
